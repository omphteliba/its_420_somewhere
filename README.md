# 4:20 Now 🌿

**It's 420 somewhere.** See where in the world it's 4:20 PM right now.

👉 **[420now.app](https://420now.app)**

## Features

- The place where it was 4:20 most recently, with a countdown to the next one
- Your own local time and when your next 4:20 comes
- A timeline of the upcoming 4:20s around the world, in your local time
- Landrace and classic cannabis strains from the current time zone
- A daily line: 4/20 and other date eggs, "Wake and bake" in the morning, weekday puns
- English and German, picked from your browser (switchable in the settings)
- Installable as an app (PWA)

## Run locally

No build step. Any static file server works:

```bash
python -m http.server 4200
```

Then open http://localhost:4200. To test a specific moment, add `?at=` with an ISO timestamp, e.g. `?at=2027-04-20T15:20:00Z`.

After changing CSS or JS, bump the `?v=` number on the `<link>`/`<script>` tags in `index.html` and `about.html` so browsers don't mix old and new files.

The leaf graphics (`icon.svg`, `leaf.svg`, `leaf-path.js`) are generated by `node tools/leaf.js`.
